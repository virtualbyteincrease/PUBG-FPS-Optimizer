# PUBG Optimizer v3.0 - МАКСИМАЛЬНЫЙ FPS + НОЛЬ ЗАДЕРЖКИ

Приложение для агрессивной оптимизации настроек PUBG с графическим интерфейсом на Python.

## 🚀 Возможности - ИГРА БУДЕТ ЛЕТАТЬ!

- 🌿 **Убрать траву** - ПОЛНОЕ удаление травы для максимальной производительности и видимости
- 🏔️ **КАРТОФЕЛЬНЫЙ ландшафт** - АГРЕССИВНОЕ снижение детализации ландшафта для максимального FPS
- 👤 **Четкие игроки** - высокая детализация моделей игроков для лучшей видимости врагов
- ⌨️ **НУЛЕВАЯ задержка инпута** - полная оптимизация инпута для минимальной задержки
- ⚡ **МАКСИМАЛЬНЫЙ FPS** - агрессивные оптимизации производительности для максимального FPS
- 🔥 **Все эффекты выключены** - тени, антиалиасинг, пост-эффекты отключены для FPS
- 🚀 **Uncapped FPS и Rendering** - полностью снимает ограничения FPS и рендеринга (как в PUBG-Experience)
- 🔊 **Улучшение звука** - оптимизация настроек звука для лучшего качества и позиционирования
- 🌿 **Частичное удаление травы** - возможность оставить траву на определенное расстояние (например, 10 метров)

## Установка

1. Установите Python 3.8 или выше
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Использование

1. Запустите приложение - оно автоматически найдет конфигурацию PUBG
2. Все оптимизации включены по умолчанию для МАКСИМАЛЬНОГО FPS:
   - ✅ Трава полностью убрана
   - ✅ Картофельный ландшафт (минимальная детализация)
   - ✅ Четкие игроки (высокая детализация моделей)
   - ✅ Нулевая задержка инпута
   - ✅ Все пост-эффекты выключены
   - ✅ Uncapped FPS и Rendering (без ограничений)
3. Нажмите "🚀 Оптимизировать" - приложение сделает всё автоматически!
4. При необходимости используйте "↩️ Восстановить" для отката изменений

**ВАЖНО:** После оптимизации перезапустите PUBG для применения настроек!

## 🔥 УЛЬТРА-КАРТОФЕЛЬНЫЙ РЕЖИМ

Приложение теперь включает **МАКСИМАЛЬНО АГРЕССИВНЫЕ** настройки:
- `r.ViewDistanceScale=0.01` (вместо 0.1) - еще более картофельный ландшафт
- `r.LandscapeLODBias=15` - максимальное снижение детализации
- `foliage.CullAll=1` - полное удаление всей растительности
- `foliage.LODBias=20` - максимальный LOD для травы
- `r.Foliage.DensityScale=0` - нулевая плотность растительности

## ⚡ Высокий приоритет процесса

Приложение **автоматически** устанавливает высокий приоритет для процесса PUBG в Windows:
- Использует `wmic` или PowerShell
- Устанавливает приоритет на **HIGH**
- Работает автоматически при оптимизации

Также создан скрипт `set_priority.bat` для ручной установки приоритета, если нужно.

## 🔧 Оптимизация драйверов и системы (НОВОЕ!)

Новая вкладка **"Драйверы"** с множеством оптимизаций для плавной игры:

### ⏱️ Таймер Windows
- Оптимизация разрешения таймера для снижения задержки

### 🖥️ Fullscreen Optimizations
- Отключение оптимизаций Windows для полноэкранного режима
- Снижает задержку ввода

### 🎮 Игровой режим Windows
- Включение игрового режима Windows
- Отключение Game Bar

### ⚡ План питания
- Установка режима High Performance
- Оптимизация энергопотребления процессора

### 🌐 Сеть
- Оптимизация TCP настроек
- Отключение Auto-Tuning для снижения задержки

### 🧠 Память
- Оптимизация использования памяти процесса

**Примечание:** Некоторые оптимизации требуют прав администратора.

## 🚀 Uncapped FPS и Rendering (НОВОЕ!)

Реализована функция из **PUBG-Experience** для полного снятия ограничений FPS и рендеринга:

### Что делает:
- ✅ **FrameRateLimit = 0** - снимает лимит FPS
- ✅ **VSync отключен** - убирает вертикальную синхронизацию
- ✅ **Динамическое разрешение отключено** - стабильный рендеринг
- ✅ **Все лимиты FPS сняты** - максимальная производительность
- ✅ **Console Variables настроены** - все параметры для uncapped режима

### Настройки применяются:
- `r.MaxFrameRate = 0`
- `r.MaxFPS = 0`
- `r.FrameRateLimit = 0`
- `r.SmoothFrameRate = False`
- `r.DynamicResolution = 0`
- `t.MaxFPS = 0`
- И многие другие параметры

**Включается автоматически** при оптимизации (можно отключить в настройках).

## 🔊 Улучшение звука (НОВОЕ!)

Новая вкладка **"Звук"** для оптимизации звуковых настроек PUBG:

### Что улучшается:
- ✅ **Увеличение каналов до 64** - больше источников звука одновременно
- ✅ **Высокое качество (48kHz)** - улучшенная частота дискретизации
- ✅ **HRTF позиционирование** - лучшее пространственное позиционирование звука
- ✅ **Больше потоков звука** - до 32 одновременных потоков
- ✅ **Улучшенный буфер** - меньше задержки звука

### Настройки применяются:
- `MaxChannels = 64`
- `SampleRate = 48000`
- `SpatializationAlgorithm = SPATIALIZATION_HRTF`
- `MaxConcurrentStreams = 32`
- И другие параметры

**Включается автоматически** при оптимизации для лучшего восприятия шагов и звуков в игре.

## 🌿 Частичное удаление травы (НОВОЕ!)

Теперь можно **выбрать**:
- ✅ **Полное удаление травы** - максимальная производительность
- ✅ **Оставить траву на N метров** - например, на 10 метров вокруг игрока

### Как использовать:
1. Откройте вкладку "Графика"
2. Выберите один из вариантов:
   - "Полностью убрать траву" - для максимального FPS
   - "Оставить траву на расстояние" - установите расстояние в метрах (5-50)
3. Настройка сохраняется автоматически

### Примеры:
- **10 метров** - трава видна только рядом, дальше пропадает
- **20 метров** - больше травы, но все еще оптимизировано
- **Полное удаление** - максимальный FPS

## 💾 Сохранение настроек

- При следующем запуске все настройки восстанавливаются автоматически
